01

Find the useful signal in a chat export

Group conversations mix decisions, tasks, repeated messages, and system metadata. Scrolling through a raw WhatsApp export makes it difficult to find an answer or recover the commitments buried in the conversation.

ContextAI ingests exported .txt files and builds a retrieval-augmented analysis workflow. A natural-language question retrieves relevant conversation context before Gemini produces a structured response.

A team hackathon project. My responsibility was the core backend architecture and the entire RAG pipeline.
02

From raw text to retrieved context

Custom parsing and regular expressions remove timestamps, system messages, and metadata noise. Cleaned message events are embedded and stored in PostgreSQL with pgvector.

WhatsApp .txt export
↓
Parse + clean message events
↓
Generate embeddings
↓
PostgreSQL + pgvector
↓
Cosine similarity · top 5 context items
↓
Gemini → structured JSON

For each question, cosine-similarity search retrieves the five most relevant context items. Those retrieved messages form the context for synthesis rather than sending every message as an undifferentiated prompt.

03

Structured answers with a clear contract

The response prompt organises output into three categories: Action Items, Decisions Made, and Key Facts. A typed JSON structure gives the consuming application predictable fields.

My implementation work covered the vector-storage model, semantic top-five retrieval, preprocessing, and prompt/output structure. The workflow supports natural-language questions and contextual task extraction.

A structured response constrains the output format. It does not, on its own, prove that every extracted fact is correct or eliminate hallucinations.

05

Delivered scope & validation questions

The README documents a working backend pipeline for ingestion, noise reduction, vector storage, retrieval, and structured synthesis. It does not report an accuracy benchmark, latency measurements, or a test-pass count.

Useful follow-up evaluation would measure retrieval relevance, factual grounding, action-item completeness, JSON validity, and performance across different chat-export formats. These remain validation questions, rather than measured project results.

06

FAQ

What does ContextAI ingest?

Exported WhatsApp .txt conversation files. Custom parsing removes system and metadata noise before embedding.

What was your contribution?

Core backend development: the RAG architecture, preprocessing, vector-storage model, top-five retrieval, and structured response prompting. It was a team hackathon project.

How is relevant context selected?

Cosine-similarity search in PostgreSQL with pgvector retrieves the five most relevant context items for the question.

Does structured JSON guarantee correct answers?

No. It gives the application a predictable output format. Retrieval coverage and factual grounding still need evaluation.
